# Portafolio Full Stack - Tamara Vega

Este proyecto es un portafolio simple y funcional con cuatro secciones: Inicio, Sobre mí, Proyectos y Contacto. Está creado con **React + TypeScript (Vite)** y utiliza **Karma + Jasmine** junto con **Testing Library** para pruebas unitarias, compilado con esbuild.

---

## Requisitos

- Node.js 18+  
- Google Chrome (para ejecutar Karma en modo headless)  

---

## Scripts disponibles

- `npm run dev` — Levanta el servidor de desarrollo de Vite.  
- `npm run build` — Compila el proyecto para producción en `dist/`.  
- `npm run test` — Ejecuta las pruebas unitarias en modo single-run (ChromeHeadless).  

---

## Estructura principal

- `src/components/` — Contiene los componentes principales: Home, About, Projects y Contact.  
- `karma.conf.cjs` — Configuración de Karma con Jasmine y esbuild.  
- `tsconfig.app.json` — Configuración para soporte de tipos Jasmine y globals.
